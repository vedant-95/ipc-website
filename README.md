# Integral Psychedelic Community website

Static site (no build step needed to host). Pages: index.html, events.html, leads.html, partners.html.

- Edit events in `assets/site.js` (EVENTS list).
- Page HTML is generated by `python3 build.py` (edit text there, then re-run).
